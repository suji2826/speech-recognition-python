# 🎤 Speech Recognition Using Python

## 📌 Overview

Speech Recognition is a Python-based application that converts spoken audio into text using speech-to-text technology. The project captures voice input through a microphone and processes it using speech recognition libraries to generate accurate text output.

This project demonstrates the practical implementation of audio processing, voice recognition, and Natural Language Processing (NLP) concepts.

---

## 🚀 Features

* Real-time speech-to-text conversion
* Microphone-based voice input
* Accurate voice recognition
* User-friendly implementation
* Fast and efficient transcription
* Beginner-friendly project structure

---

## 🛠️ Technologies Used

* Python
* SpeechRecognition Library
* PyAudio
* Google Speech Recognition API

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/suji2826/speech-recognition-python.git
```

Navigate to the project directory:

```bash
cd speech-recognition-python
```

Install the required packages:

```bash
pip install -r requirements.txt
```

---

## ▶️ Usage

Run the Python script:

```bash
python speech_recognition.py
```

### Steps:

1. Start the program.
2. Speak clearly into the microphone.
3. The system captures your voice.
4. Speech is converted into text.
5. The recognized text is displayed on the screen.
